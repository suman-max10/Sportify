# Sportify

Sportify is a full-stack sports application under development.

## Project Structure

- `frontend/` - React, TypeScript, and Vite client application
- `backend/` - Backend application (to be implemented)

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The development server will print the local URL in the terminal.

## Available Scripts

Run these commands from `frontend/`:

- `npm run dev` - Start the development server
- `npm run build` - Build the application for production
- `npm run lint` - Check the code with ESLint
- `npm run preview` - Preview the production build locally
